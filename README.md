# ctrl-ai

A security gateway for AI agents. Coding agents and SDK applications send their model and MCP tool traffic thro
ugh it, and it checks, masks, governs, rate-limits and audits that traffic from one place: prompt-injection and
 secret detection, PII masking, model governance per team, loop and budget limits, break-glass overrides, and a
 content-free audit log with an admin panel on top.

# Origin
This project continues [HackYeah2026 - ctrl.ai](https://github.com/cooPr0/hackyeah2026), which my team and I built at HackYeah in 2026. This repository is my continuation of that work: the same idea, rebuilt and expanded as a lon
g-term project.
