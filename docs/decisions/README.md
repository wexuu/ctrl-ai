# Decision records

Architecture decisions that shape ctrl-ai, one file each, numbered in the order they were raised. Each record states the context, the options considered with their evidence, the consequences and the decision (or, while it is open, the recommendation).

Status values: **Proposed** (written, waiting for a decision), **Accepted**, **Superseded by NNNN**, **Rejected**. A record is not rewritten after it is accepted; a later record supersedes it.

| No. | Title | Status |
|---|---|---|
| [0001](0001-gateway-host.md) | Gateway host: LiteLLM proxy, an own proxy, or both | Proposed |

To add one, copy the headings of an existing record (Status, Context, Options, Consequences, Recommendation or Decision) and take the next number.
